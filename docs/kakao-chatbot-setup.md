# 카카오 챗봇 연결 가이드

`kakao-orders.html`(카톡주문 정리)에 자동으로 주문이 들어오게 하려면, 카카오 쪽 설정(채널·오픈빌더)과
Firebase 배포를 순서대로 진행해야 합니다. 이 저장소에는 웹훅 코드(`functions/`)까지 준비되어 있고,
아래 단계 중 **1~3, 4~6은 카카오/구글 계정으로 직접 하셔야 하는 부분**입니다.

## 0. 전체 그림

```
고객 카톡 메시지
   → 카카오톡 채널 (카카오 비즈니스)
   → 카카오 i 오픈빌더 (봇 시나리오: 이름/연락처/상품/주소를 순서대로 질문)
   → 우리 웹훅 (Firebase Cloud Functions: functions/index.js)
   → Firestore `kakaoOrders` 컬렉션에 저장
   → kakao-orders.html 에 실시간으로 표시 (출처: 🤖 챗봇)
```

## 1. 카카오톡 채널 만들기

1. https://business.kakao.com 에서 사업자로 가입/로그인
2. "채널 만들기" → 해밀푸드 채널 생성 (프로필 사진, 카테고리 등 입력)
3. 채널 관리자센터에서 채널이 정상 개설됐는지 확인

## 2. 카카오 i 오픈빌더로 봇 만들기

1. https://i.kakao.com 접속 → 오픈빌더
2. "봇 만들기" → 1번에서 만든 채널과 연결
3. 아직 시나리오는 만들지 않아도 됩니다 (5번에서 진행)

## 3. Firebase Functions 배포 (웹훅)

이 저장소 루트에 `firebase.json`, `.firebaserc`, `functions/`가 이미 준비되어 있습니다.

```bash
npm install -g firebase-tools   # 처음 한 번만
firebase login                  # 해밀푸드 Firebase 프로젝트 계정으로 로그인
cd functions && npm install     # 의존성 설치
cd ..
firebase deploy --only functions
```

배포가 끝나면 터미널에 아래와 비슷한 **Function URL**이 출력됩니다. 이 주소를 복사해 두세요
(4번 오픈빌더 스킬 설정에서 사용합니다).

```
https://asia-northeast3-hamilfood-675ef.cloudfunctions.net/kakaoOrderSkill
```

> Firestore 보안 규칙은 따로 바꾸지 않아도 됩니다. Cloud Functions는 관리자 권한(Admin SDK)으로
> 접속하기 때문에 클라이언트용 보안 규칙과 무관하게 항상 쓰기가 가능합니다.

## 4. 오픈빌더 스킬 등록

오픈빌더 → 스킬 메뉴 → 스킬 만들기

- 스킬 이름: `주문접수`
- URL: 3번에서 복사한 Function URL

## 5. 오픈빌더 시나리오(블록) 만들기 — "주문하기"

1. 블록 추가 → 이름 `주문하기`
2. 발화 패턴에 고객이 실제로 쓸 만한 문장을 여러 개 등록 (예: `주문할게요`, `주문하기`, `주문`, `주문할래요`)
3. 파라미터(필수 항목) 추가 — 순서대로 물어봅니다:

   | 파라미터명 | 필수 | 재질문 멘트 예시 |
   |---|---|---|
   | 이름 | 필수 | 성함이 어떻게 되세요? |
   | 연락처 | 필수 | 연락 가능한 전화번호를 알려주세요. |
   | 상품 | 필수 | 주문하실 상품과 수량을 알려주세요. (예: 순대 2kg 2개) |
   | 주소 | 선택 | 배송 받으실 주소를 알려주세요. (매장에서 직접 받으신다면 "방문수령"이라고 입력해주세요) |

   > 파라미터명은 반드시 **이름 / 연락처 / 상품 / 주소** 그대로 만들어 주세요. 웹훅 코드가 이 한글
   > 이름으로 값을 읽습니다 (`functions/lib/orderSkill.js`).

4. 필수 파라미터(이름·연락처·상품)를 모두 채우면 실행할 "스킬"로 4번에서 만든 `주문접수`를 지정
5. 스킬 응답이 그대로 사용자에게 보여지도록 설정 (오픈빌더 기본 동작)

## 6. 배포 & 테스트

1. 오픈빌더 상단 "배포" 버튼으로 봇을 실제 채널에 반영
2. 카카오톡에서 해밀푸드 채널을 추가하고 "주문할게요"라고 보내서 대화 진행
3. 완료되면 사이트에 로그인해서 `kakao-orders.html`(카톡주문 정리)를 열어보면 방금 주문이
   **🤖 챗봇** 출처 배지와 함께 목록에 나타납니다.

## 참고

- 필수 파라미터가 비어 있으면(오픈빌더 쪽에서 잘못 넘어온 경우 등) 웹훅은 저장하지 않고 안내
  메시지만 응답합니다 (`functions/lib/orderSkill.js`의 `buildOrderResult`).
- 웹훅 로직은 `functions/test/orderSkill.test.js`로 단위 테스트되어 있습니다.
  `cd functions && npm test`로 실행할 수 있습니다.
- 카카오 스킬 서버는 요청 후 5초 안에 응답해야 합니다. Firestore 저장은 보통 1초 이내라 문제없지만,
  만약 타임아웃이 잦다면 오픈빌더의 "콜백" 기능(최대 1분)으로 전환할 수 있습니다.
